# Airbnb Booking & Revenue Insights Dashboard

## Project Overview
This Power BI dashboard analyzes Airbnb listings, pricing trends, customer ratings, host performance, and availability insights using interactive visualizations.

## Objectives
- Analyze Airbnb listing performance
- Understand pricing behavior
- Identify customer preferences
- Study host activity and availability trends
- Generate business insights using data visualization

## Dashboard Features
- Interactive KPI Cards
- Pricing Analysis
- Room Type Distribution
- Host Performance Analysis
- Availability Insights
- Location-Based Analysis
- Dynamic Filters & Navigation Buttons

## Tools & Technologies
- Power BI
- Power Query
- DAX
- Data Visualization

## Key Insights
- Entire home/apartment is the most preferred room type.
- Higher pricing does not always guarantee higher ratings.
- Top hosts manage multiple successful listings.
- Availability trends influence booking performance.

## Conclusion
This dashboard provides meaningful insights into Airbnb business performance and helps support data-driven decision-making using interactive Power BI visualizations.
